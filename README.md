# Chacha-Crypt
## Chacha20-Poly1305を使って暗号化する自作pyソフトです。
# このソフトの特徴
1. Exeに各種必要な物は同梱してるので、DLすればすぐに使えます。インストールも不要です。
2. 非常に強固な暗号化。暗号化にはChaCha20-Poly1305を使用しており、自由にパスワードを設定できるようになっています。指定されたパスワードはPBKDF2-HMAC-SHA256を60万回繰り返して32バイトにされ、総当たり攻撃に強いです。またランダムsaltnonceを使用しているため、同じパスワードでも中身が違います。アルゴリズムがわかりにくいわけです。そして改ざんを検知するため、1mibごとに16バイト認証タグをつけています。1文字でも書き換えると正しいパスワードでも復号できなくなります。また小分けに処理しているため、処理も高速です。
4.起動するとドラッグアンドドロップの画面が出てきます。あとは直感的にわかりますよ。ぜひ使ってみてください^^
### 留意点
1. pg83q(作者)は暗号化されたファイルの品質について一切の責任を負いません。
2. 暗号化されたファイルはパスワードを忘れると二度と復号できません。
3. 暗号化されたファイルは.chachaファイルで元のファイルがあったフォルダ・ディレクトリに保存されます。
4. Claude製です。
